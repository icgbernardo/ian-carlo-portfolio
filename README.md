# Ian Carlo Bernardo Portfolio Website

This folder is ready to upload to a GitHub repository and publish using GitHub Pages.

## Files
- `index.html` - main portfolio page
- `styles.css` - styling
- `assets/` - sanitized work-sample images and resume PDF

## Publish with GitHub Pages
1. Create a new public GitHub repository, for example `ian-carlo-portfolio`.
2. Upload all files in this folder to the repository root.
3. Go to **Settings** > **Pages**.
4. Under **Build and deployment**, set **Source** to `Deploy from a branch`.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait 1–5 minutes and open the published URL GitHub gives you.

## Optional custom URL
If you want a cleaner link, you can later add a custom domain in GitHub Pages settings.
